# Dataset folder

Download the Spotify Tracks Dataset from:

https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset/code

Rename the downloaded CSV to:

`spotify_tracks.csv`

and place it in this folder.

The website automatically loads `data/spotify_tracks.csv` when served through a local web server or GitHub Pages.

You can also use the **Load CSV** button in the website to select the file manually.
